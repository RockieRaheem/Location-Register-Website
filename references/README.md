# Reference source snapshots

This directory preserves third-party material supplied for analysis and provenance. Nothing here is imported by the runtime application.

- `uganda/boundaries-2020/` contains the original duplicate administrative boundary snapshots and the derived administrative boundary-line collection.
- `vendor/geonsanga/` contains the original MIT-licensed PHP reference implementation. Its sample environment file is stored as `.env.example`.

Runtime-ready Uganda data lives under `data/geospatial/uganda/` and `data/sources/uganda/`. See `docs/data/uganda-support-integration.md` for the authority, matching, and validation policy.
